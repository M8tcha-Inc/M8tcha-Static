# M8tcha marketing site

Static marketing site for **M8tcha**, built with Astro.

```sh
npm install
npm run dev
```

| Command           | Action                          |
| ----------------- | ------------------------------- |
| `npm run dev`     | Dev server at `localhost:4321`  |
| `npm run build`   | Production build to `./dist/`   |
| `npm run preview` | Preview the production build    |
